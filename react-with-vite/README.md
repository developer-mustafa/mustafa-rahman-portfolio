## ⚡ Core Technologies

- **Frontend**: React 19, JavaScript (ES6+), Vite, Tailwind CSS v4
- **Animation**: Motion for React (`motion`)
- **Smooth Scroll**: Lenis (`lenis`)
- **Icons**: Lucide React + custom SVG brand icons
- **Form Handling**: Client-side validation + EmailJS support

---

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start local dev server
npm run start
# Running at: http://localhost:5173

# Build production bundle
npm run build

# Preview production build
npm run preview
# Running at: http://localhost:4173
```

## 📂 Architecture

- `src/data/profile.js`: Verified personal info, main heading, philosophy, mission, and links
- `src/data/experience.js`: Verified positions (SolarWinds USA, Istanbul, Hyderabad, Madbarhat Madrasah, MMMC)
- `src/data/projects.js`: Automata Pro, Mentora Pro, SpendWise Pro, ProductMesh
- `src/data/skills.js`: Structured skills & engineering interests without fake percentages
- `src/data/education.js`: Teaching contributions, institutions, and reported academic impact
- `src/data/articles.js`: Engineering notes and insights
- `src/components/`: Modular, reusable presentation components
